Accessibility Check

WCAG 2.2 AA requires a minimum 4.5:1 contrast ratio for small text, 3:1 for large text and UI components.

Colour Hex On Ivory #FDFAF3 On Navy #0F2347 Verdict
Gold (existing) #C9A84C 2.19:1 6.80:1 Ivory: FAILS   Navy: AAA
Gold Dark (existing) #8C651E 4.85:1 11.2:1 Ivory: AA ✓   Navy: AAA ✓

Pine Sage #4E7A5F 4.81:1 9.64:1 Ivory: AA ✓   Navy: AAA ✓
Copper #8B5E3C 4.62:1 9.26:1 Ivory: AA ✓   Navy: AAA ✓

All three candidates pass WCAG AA in both dark and light contexts. Use sparingly — 3 touches maximum on the full site.
