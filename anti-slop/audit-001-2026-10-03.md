# Antislop Audit 001

- Target: `programmes.html`
- Date: 2026-10-03
- Mode: Mode 2 (After Project Creation Audit)

## Findings List

### 1. [HIGH] Rule R-03 (Mobile Responsiveness & Touch Targets)
- Element: `.nav-cta` in top navigation bar.
- Finding: Currently set to `min-height: 42px`, which falls 2px short of the mandatory 44x44px minimum touch target standard for mobile ergonomics.
- Recommended Fix: Increase `.nav-cta` min-height to 44px with 44px minimum tap area.

### 2. [MEDIUM] Rule R-03 / C-4 (Mobile Navigation Graceful State)
- Element: `.nav-links` at `@media (max-width: 640px)`.
- Finding: On mobile screens under 640px, navigation links are hidden with `display: none` without an accordion or mobile drawer trigger, leaving mobile guests unable to navigate directly between subpages without scrolling to the footer.
- Recommended Fix: Add an elegant, accessible mobile navigation drawer or sticky quick-jump pill bar for mobile visitors.

### 3. [LOW] Rule R-31 (Typography & Devanagari Kerning Harmony)
- Element: `.shloka-script` inside `.shloka-header-card`.
- Finding: The Sanskrit Devanagari text `स्वस्थस्य स्वास्थ्यरक्षणम्` has a default `letter-spacing: 0.06em`, which can slightly detach continuous Devanagari top-line (Shirorekha) ligatures on certain mobile webkit engines.
- Recommended Fix: Set `letter-spacing: normal` specifically for `.shloka-script` while preserving optical padding, maintaining seamless Devanagari ligature rendering.

### 4. [LOW] Rule C-2 (Interactive State Feedback)
- Element: `.pricing-option` rows in programme cards.
- Finding: Double vs. Triple occupancy prices are static text blocks without visual hover or active state distinction to emphasize occupancy savings.
- Recommended Fix: Add subtle interactive micro-highlight on hover over occupancy rows to aid readability.
